# Progetto-W-3

Questa pagina web sarà, più o meno simile, ad una playlist con alcuni dei miei brani preferiti.
Avrà anche la possibilità di passare dal tema chiaro a quello scuro.
Sono partito da un'immagine di riferimento e ho provato a farla il più simile possibile.
Questa pagina avrà:

- Una barra di ricerca.
- Una lista di canzoni ed ogni canzone avrà la copertina, il tiolo, l'artista, il genere, le stelline del voto, il cuoricino per le preferite ed un tasto per rimuovere una canzone alla volta.
- Un filtro per genere di musica.
- Una sezione preferiti.
- Un bottone che servirà per passare dal tema chiaro a quello scuro.
